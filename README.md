# FURBTok

Simulação de feed estilo Reels/TikTok para o Seminário 10 de Administração Geral (FURB): *Análise de Big Data e desempenho corporativo*.

- `index.html`: o feed (celular) e o painel da turma (`#painel`, para o telão).
- Os vídeos são Shorts públicos do YouTube, exibidos pelo player oficial (embed).
- Os dados de cada pessoa (tempo por tema, curtidas e pulos) vão para o backend definido em `BACKEND`, no início do script.
